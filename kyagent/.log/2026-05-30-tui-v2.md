# 2026-05-30 TUI v2 重写

**分支**: experimental/tui-streaming
**文件**: kyagent/tui.py（覆盖式 Write）

## 要点

- **Per-message Panel**：用户输入立即 `console.print(Panel(border=green, title="你"))`；agent_final 后 Live 退出再打印 `Panel(border=blue, title="kyagent")`。两者各自独立进 scrollback，不再框在统一对话 Panel 内。
- **Live 区只放变化部分**：`_render_live()` = 思考 Panel（dim italic grey50）+ status 行。`transient=True`，Live 退出时擦除，最终回答 Panel 单独打印。
- **流式思考**：`thinking_delta` 事件 append 到 `self._thinking_buffer: list[str]`，超 2000 字头部省略号 + 尾 1500。`agent_start` 时清空 buffer。
- **颜色对比**：思考 `dim italic grey50`，agent 回答 `white`，肉眼可辨。
- **Ctrl+L**：`prompt_toolkit.KeyBindings` 绑定 c-l → `console.clear()` + `app.invalidate()`。无 prompt_toolkit 时跳过。
- **ask_user_choice**：`prompt_user_choice` 临时 stop Live → 打 yellow Panel 列选项 → `_raw_prompt` 拿序号或 value → restart Live。`on_user_choice_fn` 暴露给 TuiSession→Agent。
- **兼容**：TuiSession.from_config 透传 `on_user_choice`，TypeError 时降级。
- 顶层导出齐：TuiApp/TuiSession/run_tui/confirm_request_lines/tool_rows。
