# 工作日志 2026-06-05：写操作工具扩展

## 任务
为 MCP 工具集新增 5 个写操作工具，补全静态测试。

## 新增工具
1. **LogVacuumTool** (`logs.py`) — `log_vacuum`，journalctl 日志回收，MEDIUM 风险，root
2. **ProcessKillTool** (`process.py`) — `process_kill`，kill 信号，HIGH 风险，root，pid≥2 强制
3. **PkgInstallTool** (`package.py`) — `pkg_install`，dnf/yum 安装，MEDIUM 风险，root
4. **PkgRemoveTool** (`package.py`) — `pkg_remove`，dnf/yum 卸载，HIGH 风险，root
5. **FsTruncateTool** (`filesystem.py`) — `fs_truncate`，文件清空，HIGH 风险，root，路径限 /var/log 等

## 关键约束
- 所有工具 read_only=False, requires_root=True
- LogVacuumTool：max_size/max_age 二选一，否则 ToolError
- ProcessKillTool：pid minimum=2，禁止 kill init
- FsTruncateTool：复用 _safe_path()，路径限 /var/log/、/var/cache/、/var/tmp/、/tmp/
- 包名 pattern `^[A-Za-z0-9._+-]+$` maxLength 100
