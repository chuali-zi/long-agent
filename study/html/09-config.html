配置系统
Pydantic + YAML + 环境变量

对应文件 kyagent/config.py + configs/{default,openai}.yaml。 强类型校验、环境变量友好、零配置兜底。

1 设计目标

1
强类型

2 Pydantic schema 树

Config ├── agent: AgentConfig │ ├── name: str = "kyagent" │ ├── llm_backend: str = "mock" ★ "anthropic" / "openai" / "mock" │ ├── anthropic: AnthropicConfig │ │ ├── model: str = "claude-opus-4-7" │ │ ├── max_tokens: int = 4096 │ │ └── api_key_env: str = "ANTHROPIC_API_KEY" │ ├── openai: OpenAIConfig │ │ ├── model · max_tokens · temperature │ │ ├── api_key_env · base_url · organization │ └── max_iterations: int = 8 ├── executor: ExecutorConfig │ ├── account: str = "kyagent" │ ├── timeout: int = 30 │ ├── output_cap: int = 65536 │ ├── forbid_root: bool = True │ └── path: list[str] = ["/usr/local/bin","/usr/bin","/bin"] ├── safety: SafetyConfig │ ├── rules_file: str = "configs/safety-rules.yaml" │ ├── policy: SafetyPolicy │ │ ├── critical: str = "deny" │ │ ├── high · medium: str = "confirm" │ │ └── low: str = "allow" │ └── llm_review: bool = False ├── audit: AuditConfig │ ├── database: str = "./var/audit.db" │ ├── jsonl_file: str | None = "./var/audit.jsonl" │ └── retain_days: int = 90 ├── mcp: McpConfig │ ├── enable_tools: list[str] = [] # 工具白名单 │ ├── server_name · server_version └── base_dir: Path = Path.cwd()

每一个 *Config 都是一个 pydantic.BaseModel，字段都带默认值，所以即便整段配置缺失也能正常构造。

3 环境变量展开

config.py:13 · _expand_env 正则
_ENV_PATTERN = re.compile(r"\$\{([A-Z_][A-Z0-9_]*)(?::-(.*?))?\}")

# 支持两种语法：
${KYAGENT_LLM_BACKEND}           # → 取环境变量，无值时变空字符串
${KYAGENT_LLM_BACKEND:-mock}     # → 取环境变量，无值时回退 mock
1
递归处理 dict 和 list，所以 path: ["${A:-/usr/bin}"] 这种也能展开
2
变量名必须以字母或下划线开头，后续只允许大写字母 / 数字 / 下划线 — 保守命名避免误把 ${something} 当变量

config.py:108 · find_default_config 优先级
1. os.environ.get("KYAGENT_CONFIG")       # 环境变量指向的文件
2. Path.cwd() / "configs" / "default.yaml" # 当前工作目录

5 Config.resolve · 相对路径锚点

def resolve(self, p: str | Path) -> Path:
    path = Path(p)
    if path.is_absolute():
        return path
    return (self.base_dir / path).resolve()

把相对路径解析成绝对路径，参照 base_dir：

  • audit.database: ./var/audit.db + base_dir=D:\race\long\ → D:\race\long\var\audit.db

所有需要落地的路径都过 cfg.resolve()，避免相对路径在 CWD 改变时出错。

6 default.yaml · mock 后端

configs/default.yaml
agent:
  name: kyagent
  llm_backend: ${KYAGENT_LLM_BACKEND:-mock}
  anthropic:
    model: claude-opus-4-7
    max_tokens: 4096
    api_key_env: ANTHROPIC_API_KEY
  max_iterations: 8

executor:
  account: kyagent
  timeout: 30
  output_cap: 65536
  forbid_root: true
  path:
    - /usr/local/bin
    - /usr/bin
    - /bin
    - /usr/sbin
    - /sbin

safety:
  rules_file: configs/safety-rules.yaml
  policy:
    critical: deny
    high: confirm
    medium: confirm
    low: allow
  llm_review: false

audit:
  database: ./var/audit.db
  jsonl_file: ./var/audit.jsonl
  retain_days: 90

mcp:
  enable_tools: []
  server_name: kyagent
  server_version: 0.1.0
1
默认 llm_backend: mock，离线可跑
2
用 KYAGENT_LLM_BACKEND 覆盖（KYAGENT_LLM_BACKEND=anthropic kyagent ask "..."）
3
forbid_root: true 默认禁用 root 提权
4
enable_tools: [] 空白名单 = 全部启用
5
llm_review: false 默认关闭 LLM 复审

10 关键不变量

1
配置加载是同步、惰性的：第一次 load_config() 才读 YAML
2
cfg.base_dir 是相对路径的锚点：永远是 configs/ 的父目录（项目根）
3
yaml.safe_load 而非 yaml.load：杜绝 YAML 反序列化攻击
4
环境变量展开是字符串值上做的：dict key / 数字字段不展开
5
配置不存在不报错：全默认兜底，让「零配置启动」成立
