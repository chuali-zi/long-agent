# LoongArch64 / Kylin V10 default dependency set for kyagent.
#
# This file is intentionally narrow. It is the default deployment path used by
# scripts/install-loongarch.sh and must stay free of optional LLM SDK packages
# and Rust extension dependencies. Real LLM access on LoongArch Old World should
# use configs/deepseek.yaml with KYAGENT_DEEPSEEK_TRANSPORT=deepseek_httpx.
#
# Pydantic/PyYAML note:
#   The installer uses:
#     SKIP_CYTHON=1 pip install --no-binary PyYAML,pydantic -r requirements-loongarch.txt
#     SKIP_CYTHON=1 pip install --force-reinstall --no-binary pydantic "pydantic>=1.10.13,<2"
#   when repairing an existing venv, so pip never installs unconstrained
#   pydantic v2 before the requirements pass brings it back to v1.
#   Pydantic v1 can optionally compile Cython extensions. SKIP_CYTHON=1 keeps
#   the conservative LoongArch path pure Python.
#   On LoongArch, PyYAML may try to build the optional libyaml C extension.
#   If libyaml headers are missing, setup falls back to the pure Python loader;
#   this is acceptable for kyagent. The default path is zero Rust and has no
#   required C extension.
